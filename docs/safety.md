# 安全机制说明（§8/§10/§13）

> 防止误打分是系统最高优先级。任何情况下都不能因为页面识别错误给学生打错分。

## 1. 默认锁死的三道闸门

| 能力 | 默认 | 开闸 |
|---|---|---|
| 真实点击分数按钮 | ❌ DRY RUN（只高亮「建议点击：N」） | `dryRun=false` 且 `phase>=2` |
| 程序点击「提交」 | ❌ | `phase>=3` 且 `allowSubmit=true` 且自动提交状态可确认且判定 `auto` |
| 完全无人值守提交 | ❌ 禁止（开发阶段） | `allowAutoSubmit=true` |

闸门在 `automation/gates.ts` 实现，抛 `SafetyGateError(code, 中文说明)`；任何闸门拒绝都会被状态机转为 PAUSE 或记录为「等待教师」，**不会悄悄放行**。

## 2. 置信度裁决（§8，默认阈值可配置）

```
综合置信度 = min(识别置信度, 评分置信度)          ← 保守策略
多模型分差 >= maxModelDisagreement(3)            → 强制人工复核（优先于置信度）
综合置信度 >= minConfidenceAuto(0.90)            → 可自动提交
综合置信度 >= minConfidenceTeacherConfirm(0.75)  → 教师确认
否则                                              → 强制人工
```

- 识别置信度：Vision 自评 × OCR 交叉校验（重合度 < 0.4 强制压到 ≤50% 并告警）。
- 评分置信度：要求模型考虑「转录可能不清晰、内容过短、疑似漏拍」等不确定性并显著降低。
- 识别到「未识别到作文内容」→ 置信度 0 → 必然人工。

## 3. 七项防误打保护（§13）

每次 `CHECK_PAGE` 与 `VERIFY_SCORE` 都执行并记录到 action_log：

1. **当前题号识别**（配置了 `expectedQuestionNumber` 时硬校验，不符直接 STOP；平台不显示题号时依赖其余保护）
2. **当前学生识别**（评分前后身份必须一致，防止页面被切换时误填；平台无学生信息时由「作文内容签名」兜底切换检测）
3. **作文区域存在检测**
4. **评分区域存在检测**
5. **当前分数状态检测**（DRY RUN 断言未被意外修改；live 断言已正确填入目标分）
6. **提交状态检测**（自动提交开关状态可确认；提交按钮存在）
7. **页面变化检测**（NEXT_ESSAY 等待学生切换；SUBMIT 后确认页面已变化）

**任一检查失败 → STOP（PAUSE + 明确错误），绝不继续。** 测试覆盖了题号硬校验、身份变化检测、分数未被修改等场景。

## 4. 提交策略（§10）

- 启动后先读取平台「自动提交」开关状态：**只检测，绝不修改用户设置**。
- 平台已开自动提交 → 记录 `platform_auto`，由平台自行提交。
- 平台未开 → 默认 `pending_teacher`：评分→确认→**等待教师确认后提交**。
- 只有 verdict=auto 且闸门全部通过才会程序点击提交；低置信度/需教师确认的作文一律等待教师。

## 5. 登录与验证码（§2）

- 程序不保存/读取/索要任何平台账号密码，不自动登录。
- `PageAnalyzer` 检测到 验证码/短信验证/二次认证/登录过期 文案 → `intervention_needed` → PAUSE + 面板提示「请人工处理」，处理完点「继续」。
- 不存在任何绕过验证码/安全验证/风控的代码路径。

## 6. 其他防线

- **作文区域越界防护**：定位区域占视口 > 75%（`maxRegionFraction`）视为定位错误，拒绝截图（防止把整页发给 AI）。
- **分数钳制**：模型分数必须是 0..max 整数，越界钳制并记录原因；JSON 解析失败抛错 → PAUSE（绝不猜分）。
- **按钮定位失败即停**：找不到目标分数按钮 → PAUSE（绝不点「附近」的按钮）。
- **日志审计**：每次操作（含被拦截的）都写入 `action_log`，可完整回放每个学生的处理过程。
- **面板独立页兜底**：平台 CSP 阻止注入面板时，独立面板页保证教师始终能 暂停/继续/停止。

## 6.5 评分校准（学习教师尺度）的安全边界

- 校准只作用于「建议分」，**不改变置信度裁决、不绕过任何提交闸门**；
- 修正量封顶 `maxAdjust`（默认 ±3 分），防止个别样本过度拟合；
- 样本不足 `minSamples`（默认 10 份）不修正；|平均偏差| < 0.5 不修正；
- 数据集按评分标准 id 隔离（换考试/换标准自动换数据集，绝不串用）；
- 只使用「教师实际分数」与「AI 原始分数」的差值，不含学生个人信息；
- 可随时在面板「大模型设置」里重置，重新开始学习。

## 7. 上真实平台前必读

1. 保持 `dryRun=true, phase=1`，跑 `npm run analyze` + 观察高亮；
2. 核对 `essay-XXXX.json` 中 `score_button_method` 是 role/text 定位而非视觉猜测；
3. 随机抽查若干份日志的作文文本与分数是否合理；
4. 全部通过后再逐级开闸（见 `docs/phases.md`），并小批量试批。
